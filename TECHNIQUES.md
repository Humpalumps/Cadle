# TECHNIQUES.md — vetted open-source three.js techniques (licenses verified 2026-08-20)

Ranked best value-for-effort. "STEAL" = lift the technique/shader into your owned files (with a source comment + license notice where required). Target: WebGL2, plain ESM, three r185 + postprocessing 6.39. Do NOT add npm deps without a report note; prefer inlining shader code.

1. **N8AO** — github.com/N8python/n8ao — **CC0** (no attribution needed). SSAO/HBAO hybrid, temporally stable, ships `N8AOPostPass` for pmndrs postprocessing (needs RenderPass before it). Drop-in. Best AO-per-ms in three. → **postfx builder**: replaces the invisible SSAO.
2. **Quick_Grass (SimonDev)** — github.com/simondevyoutube/Quick_Grass — **MIT**. Ghost-of-Tsushima blades: instanced tapered strips, vertex wind (sine + scrolling noise), view-dependent blade thickening, distance LOD (fewer verts far). Plain ESM already. → **grass builder**: blade shape/curvature + wind scheme (fixes "rigid daggers").
3. **three-good-godrays (Ameobea)** — github.com/Ameobea/three-good-godrays — **zlib-style permissive (keep notice)**. Screen-space raymarched god rays sampling the real shadow map → shafts respect occluders (vs radial-blur GodRaysEffect's milky veil). Built for pmndrs postprocessing. Needs a small patch for r185 depth-packing (fix documented at cprimozic.net/notes/posts/updating-three-good-godrays-for-threejs-182/). Half-res + blur. → **postfx builder**: THE god-rays fix.
4. **three-hex-tiling (Ameobea)** — github.com/Ameobea/three-hex-tiling — **MIT**. Hex-tile stochastic blending kills texture repetition; patches MeshStandardMaterial via onBeforeCompile; ≤3 fetches/fragment. Inline the GLSL (declared range is old three, treat as shader source). → **terrain builder**: use with the new albedo textures (assets/tex) for tiling-free splats.
5. **@three.ez/instanced-mesh (agargaro)** — github.com/agargaro/instanced-mesh — **MIT**. InstancedMesh2: per-instance frustum culling, BVH raycast, per-instance LOD/visibility. Behind the 200k-trees demos. → **vegetation builder**: at least steal the pattern (chunked instancing + per-instance culling + LOD).
6. **octahedral-impostor (agargaro)** — github.com/agargaro/octahedral-impostor — **MIT**, WIP. Runtime octahedral view-atlas bake → single-quad impostors picking/blending frames by view direction (Fortnite technique). → **vegetation builder**: far-LOD trees (fixes black cardboard cutouts). Lift technique, not the package.
7. **three-geospatial / @takram/three-atmosphere + three-clouds** — github.com/takram-design-engineering/three-geospatial — **MIT**. Best open Bruneton atmosphere + AAA volumetric clouds in three. TS/R3F/planet-scale = moderate-hard port. → **sky builder**: reference for atmosphere LUT shaders + cloud raymarch structure (multiscatter approx, temporal upscale). Simpler port base: jeantimex/precomputed_atmospheric_scattering (BSD-3, keep notice; verify).
8. **volumetric-clouds (leoawen)** — github.com/leoawen/volumetric-clouds — **MIT**. Single-file commented WebGL2: FBM baked to 3D texture, raymarch with scattering/absorption, depth pre-pass, god-ray occlusion. Perf varies — render quarter-res + upsample. → **sky builder**: the realistic path to real cumulus (fixes noise-slice clouds). (Faraz "Nubis Evolved" repo = NO LICENSE, ideas only, never copy.)
9. **Lake water** — use installed `three/addons/objects/Water.js` / `Reflector.js` (MIT, already in node_modules) as the planar base + own shader for depth absorption, foam band, glitter. jbouny/fft-ocean (MIT) only if open-water waves needed. "Three.js Water Pro" is paid/WebGPU — skip. → **water builder**: trust the crisp mirror (critic), simple compositing.
10. **FF14 painterly grade** — three r185 has AgX/ACES in core; installed postprocessing has LUT3DEffect/HueSaturation/Bloom. Hand-generate a 3D LUT procedurally (canvas) for saturated-but-soft. Reference: blog.maximeheckel.com/posts/on-crafting-painterly-shaders/ (anisotropic Kuwahara — expensive, half-res or skip). NOT cel/toon — FF14 is painterly-realistic. → **postfx builder**.
11. **realism-effects (0beqz)** — MIT — SSGI/TRAA/velocity buffers. Stalled, heavy, fog issues. Skip except velocity-buffer pattern if TAA ghosts.
12. **three-mesh-bvh (gkjohnson)** — MIT — BVH raycast acceleration. Only if hitscan shows in profiler. → combat.

License flags: thebenezer/FluffyGrass + nwpointer/three-landscape = license unverified, technique reference only. Anything WebGPU/TSL-only: deprioritize.
